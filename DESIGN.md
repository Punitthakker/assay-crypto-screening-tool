# DESIGN.md - Assay

World: an offensive-security terminal. Hard edges, hairlines, uppercase, numerals with leading zeros. Motion is data moving: a decode-scramble on the headline, a live terminal replaying recorded screening sessions line by line (typed command, hex scan streams, hop counters, a filling risk meter, verdict stamp), a ticker of checks under the nav, and a faint hex rain behind the hero. Nothing bounces, nothing is a game.

Surfaces: near-black steel `#050709`, raised `#0B0F13`, hairlines `#161C22` / `#232C35`, a 64px hairline grid on the hero only. Text `#E8EDF2`, secondary `#8B98A6`, tertiary `#56636F`.
Accents: terminal green `#4CFF7A` (with `#39D96B` for green code lines) for the single call to action and CLEAR; hard red `#FF2E3F` for BLOCK and hard-block tags; amber `#FFB020` for CAUTION, pending phases and disabled coverage. Never more than one acid element per viewport.
Type: Orbitron 800 uppercase for the headline, h2, wordmark, buttons and readout numerals (400 for the muted half of the headline); Chakra Petch 600 for h3 and tags. JetBrains Mono for body, data, code and labels. Tabular numerals everywhere.
Shapes: square corners only. Borders, never shadows. Tags are 1px outlined boxes. Meters are flat bars.
Motion: as above, all respecting prefers-reduced-motion (static final frames). Hover changes a border colour only.
Icons: authored SVG, 1.6px stroke, square caps, miter joins, 20px grid.
Layout: specification tables and a bordered matrix instead of cards. No eyebrow labels above headings except the single section tag. No gradient text, no glass, no glow.
Logo: square stencil with an A whose crossbar is replaced by a full-width acid line (the assay line). Wordmark ASSAY in Chakra Petch 700, tracked .18em.
