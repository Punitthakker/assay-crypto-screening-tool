Layer 02 - How to run it

Ten minutes on your Mac

Node 20 or newer and pnpm. Nothing else. No API keys.

# 1. unpack and install

npm i -g pnpm && pnpm install

# 2. prove the engine offline (14 tests, recorded fixtures)
pnpm test

# 3. first live run: verifies every contract, oracle and list, writes docs/SOURCES.verified.json
pnpm verify:sources

# 4. screen real addresses
pnpm screen TR7NHqjeKQxGTCi8q8ZY4pL8otSzgjLj6t -a USDT
pnpm screen 0x28C6c06298d514Db089934071355E5743bf21d60 -c ethereum -a USDT
pnpm screen <addr> -c base -a USDC -m 25000      # amount turns on the Travel Rule check
pnpm screen <addr> -c base -a USDC --json

# offline demo mode, and recording live responses into fixtures
CR_TRANSPORT=fixture pnpm screen ...
CR_RECORD=1 pnpm screen ...
Exit codes0 clear, 3 BLOCK, 1 error, 2 bad input. Pipelines can gate on it directly.
0x addresses need --chainThe same address has a different freeze state on each EVM chain. Tron and Solana are inferred from the address format.
verify:sources must pass once before any demoThe build sandbox has no blockchain access, so every on-chain fixture was hand-encoded. The script probes the USDT0 contracts for their real blacklist method and confirms the oracle with a live positive control.
